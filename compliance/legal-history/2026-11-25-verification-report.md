# Legal source verification, 2026-11-25

Every requirement in the seven registers below was checked against official text fetched in this session. A requirement is marked `source_verified: true` only when the text of every section its required behaviour relies on was read and supports it. Everything else stays unverified (audits treat it as BLUE), with the reason appended to its notes.

Verified requirements carry `last_verified: 2026-11-25`, the date the task set. The run was interrupted by a rate limit, so some sources were actually read on 2026-11-27, all within this one verification session.

## Sources that could be read

- **US Code**: uscode.house.gov, at `https://uscode.house.gov/us/usc/t<T>/s<S>/`. The site runs in a temporary format, and the `view.xhtml?req=granuleid:...` form returns 404.
- **CFR**: eCFR (www.ecfr.gov), read through the eCFR renderer API (`/api/renderer/v1/content/enhanced/current/...`), which returns the current regulation text. The human-readable `https://www.ecfr.gov/current/...` URL is the one recorded.
- **Cal. Bus. & Prof. Code §§ 7000-7199 and 16 CCR (CSLB rules)**: CSLB, *2026 California Contractors License Law & Reference Book* (https://www.cslb.ca.gov/Resources/GuidesAndPublications/2026/2026_CSLB_Law_Book.pdf), current to laws effective January 1, 2026. Since 2024 the book leaves out non-B&P codes such as the Civil and Labor Codes.
- **CCPA statute** (Civ. Code 1798.100 et seq., effective Jan. 1, 2026): https://cppa.ca.gov/pdf/20260101_ccpa_statute.pdf
- **CCPA regulations** (11 CCR 7000 et seq., consolidated, effective Jan. 1, 2026): https://cppa.ca.gov/regulations/pdf/ccpa_statute_eff_20260101.pdf. Despite the file name, CPPA links this file as "CCPA Regulations (Effective January 1, 2026)".
- **WCAG 2.2**: www.w3.org (the Recommendation and the Understanding pages).
- Agency pages on www.ada.gov, www.irs.gov, oag.ca.gov, cppa.ca.gov, www.cslb.ca.gov and www.pcisecuritystandards.org, where cited.

## Sources that could not be read

- **leginfo.legislature.ca.gov** answers every request with a Cloudflare bot challenge whose challenge host is not on the allowlist. California sections that are not in the CSLB Law Book or the CPPA PDFs therefore could not be read. These include Civ. Code 51-55, 1633.x, 1689.x, 1770, 1798.81-1798.83 and 8000+, the Penal Code, the Labor Code, the Rev. & Tax. Code, and B&P 17200+ and 22575+.
- **www.ftc.gov, www.fcc.gov and docs.fcc.gov** reject automated requests with HTTP 403. No attempt was made to get around this.
- Hosts outside the allowlist (for example law.cornell.edu, consumerfinance.gov, federalregister.gov, nacha.org, stripe.com, CTIA/Twilio, cdtfa.ca.gov, supremecourt.gov) were not contacted.
