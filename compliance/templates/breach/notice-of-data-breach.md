# Notice of Data Breach (template)

> **Draft for counsel.** The title and headings below follow the format described in register entry CA-004-003 (Cal. Civ. Code 1798.82). That entry was written without reading the enacted text. Counsel must confirm the headings, the required content, the type size and any no-cost identity protection offer before this template is used. Requirements: SEC-006-007, CA-004-003.
>
> Format: plain language. The title and headings are displayed conspicuously, and no text is smaller than 10-point type. Fill in every [bracket]. Delete any line that doesn't apply, only on counsel's advice.
